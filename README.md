# SURVAE · EKT Ассистент

AI-консультант для электротехнического магазина: помогает покупателю описать задачу обычными словами, уточняет условия, находит товары, сравнивает аналоги и готовит проверяемый список заказа. Корзина изменяется **только после явного подтверждения**.

Проект команды SURVAE для HackAlem AI, трек «Торговля», кейс ekt.kz / Электрокомплект. Разработка велась с OpenAI Codex. Нейросеть не обучалась; используется API готовой модели.

## Что реализовано

- Свободный диалог с контекстом и защитой от повторных вопросов; запросы вне профиля магазина обрабатываются отдельно.
